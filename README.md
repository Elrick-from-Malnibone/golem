# Golem

Металлический конструкт для анализа кода. Ломает баги, строит README, пишет посты в канал. Не спрашивай, зачем — просто работает.

## Установка

```bash
git clone https://github.com/yourname/golem.git
cd golem
pip install -r requirements.txt
```

Настрой `config.py`:
- Telegram Bot Token
- DeepSeek API Key
- GitHub Token (опционально)

## Запуск

```bash
python main.py
```

Бот запустится, начнёт слушать команды. Не тормози — он этого не любит.

## Использование

### Анализ кода
```
/analyze — загрузи Python/Go проект (ZIP или GitHub ссылку)
```
Проверит уязвимости, стиль, безопасность. Выплюнет отчёт.

### Автофикс
```
/fix — попробует починить найденные проблемы
```
Только для Python (Ruff) и Go (golangci-lint). Не гарантирую, что не сломает.

### GitHub
```
/github_push — загрузит README в репозиторий
/set_github_token — привяжи токен
```

### Канал
Автоматически генерирует посты по расписанию:
- Понедельник/Четверг: горячие новости
- Вторник/Пятница: чёрный юмор
- Среда/Суббота: код и баги
- Воскресенье: рофлы

Рефлексия по пятницам. Не спрашивай.

### Память
```
/remember — сохрани что-то
/recall — вспомни
/forget — сотри
```
SQLite под капотом. Не теряется.

## Технологии
- Python, aiogram, asyncio
- DeepSeek API для анализа
- Ruff, Bandit, Semgrep для Python
- golangci-lint, govulncheck для Go
- SQLite для памяти пользователей
